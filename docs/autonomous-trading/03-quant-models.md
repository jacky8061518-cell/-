# 03 量化模型層

## 1. 特徵設計原則

**特徵不是越多越好，是越「不相關」越好。** 200 個都在講同一件事的動能指標，
等於只有 1 個特徵加 199 份雜訊。每加一個特徵要能回答：它捕捉了哪個既有特徵
沒捕捉到的市場機制？

四個相對正交的家族：

| 家族 | 捕捉什麼 | 代表特徵 |
| --- | --- | --- |
| **價格結構** | 趨勢與均值回歸 | 多週期動能、相對強弱、距均線偏離、RRG 象限 |
| **風險與流動性** | 交易成本與尾部 | 已實現波動、下檔半變異數、成交量比、價差、Amihud 非流動性 |
| **資金與部位** | 錢在動 | 法人買賣超、融資餘額變化、ETF 申贖、選擇權未平倉偏斜 |
| **資訊與情緒** | 敘事與預期 | 新聞強度、情緒變化率、分析師調升廣度、事件驚訝度 |

現有 repo 的 `compute_momentum_components()` 已涵蓋第一家族，
`fund_flow.py` 涵蓋第三家族。第二、四家族是要新增的部分。

## 2. mean 與 standard deviation：正確地用

使用者提到要算 mean / std。這在金融資料上有幾個一定要處理的陷阱：

### 2.1 用穩健估計取代樣本統計

金融報酬是厚尾的。單一 -18% 的跳空會把 20 日 std 拉高，讓後續所有 z-score
失真。做法：

```text
中位數                  m = median(x)
中位數絕對離差           MAD = median(|x - m|)
穩健標準差              σ̂ = 1.4826 × MAD
穩健 z-score            z = (x - m) / σ̂
```

需要保留尾部資訊時再另外算真實 std 當作獨立特徵（波動率本身就是訊號）。

### 2.2 用什麼視窗

不要只用一個。同時算 **短（20）/ 中（60）/ 長（252）** 三個視窗，
並把「短期 σ ÷ 長期 σ」當成 **波動率 regime 特徵**（>1.5 代表進入高波動狀態）。

### 2.3 EWMA 而非等權

近期資料更相關。用指數加權：

```text
μ_t = λ·μ_{t-1} + (1-λ)·x_t
σ²_t = λ·σ²_{t-1} + (1-λ)·(x_t - μ_t)²
λ 常用 0.94（日資料，RiskMetrics 慣例）
```

### 2.4 橫斷面標準化才是重點

「台積電漲 3% 是不是異常」不該只跟它自己的歷史比，要跟**同一天所有半導體股**比。
兩種標準化都要有：

- **時序 z-score**：`(x_it - μ_i) / σ_i` — 對這檔股票而言多不尋常
- **橫斷面 z-score**：`(x_it - μ_t) / σ_t` — 在今天的同業中排第幾

實務上橫斷面排名（rank → 轉常態）比原始 z-score 穩健很多，因為它對離群值免疫。
現有 `fund_flow.py` 的 `_rank_score()` 就是這個做法，應推廣到所有特徵。

### 2.5 一定要做的清理

- **winsorize** 在 1% / 99% 分位，避免單一錯誤報價毀掉整個模型
- **產業中性化**：把特徵對產業 dummy 做回歸，取殘差。否則你的「動能訊號」
  可能只是「今天買了半導體」
- **市值 / beta 中性化**：同理，避免訊號其實是隱藏的 beta 曝險

## 3. 情緒的量化

把 [02](02-agents.md) 的 LLM 輸出轉成可用的數值特徵：

```text
單則新聞得分  s_j = polarity_j × materiality_j × novelty_j × tier_weight_j
時間衰減      w_j = exp(-Δt_j / τ)     τ 依 horizon 而定
                                       intraday τ=2h, days τ=2d, weeks τ=10d
標的情緒      S_it = Σ_j (s_j × w_j) / (1 + Σ_j w_j)     ← 分母防止「多則低品質新聞」灌水
```

**四個關鍵衍生特徵，比 S 本身有用**：

1. `ΔS`（情緒變化率）— 邊際資訊才會推動價格
2. `S_dispersion`（同一標的各來源的情緒標準差）— 分歧度高代表事件未定價
3. `S_surprise = S - E[S | 過去 60 日]` — 相對於常態的驚訝程度
4. `attention = 新聞則數的 z-score` — 注意力本身是獨立於方向的訊號

## 4. 從特徵到訊號：不要只用一個模型

### 4.1 三層堆疊

```text
Layer 1  多個弱模型並行（各自獨立、可解釋）
         ├─ 動能／輪動模型（現有 strategy.py）
         ├─ 均值回歸模型（適用於高波動、低趨勢 regime）
         ├─ 資金流跟隨模型
         ├─ 事件驅動模型（財報、法說、政策）
         └─ 梯度提升樹（LightGBM）吃全部特徵
                       ↓
Layer 2  Regime 條件加權（不是簡單平均）
         w_k(regime) 由歷史上各模型在該 regime 的表現決定
                       ↓
Layer 3  Meta-labeling：另一個模型只回答「這個訊號該不該執行」
         輸入＝Layer 2 的方向訊號 + 市場狀態 + 訊號自身特徵
         輸出＝執行機率 p ∈ [0,1] → 直接轉成部位大小
```

**Meta-labeling 是這套系統最值得投資的一塊。** 分開處理「方向」與「該不該押」
比一個模型同時做兩件事準確得多，而且它天然產出風控需要的信心分數。

### 4.2 標籤怎麼設（比模型選擇更重要）

不要用「未來 5 日報酬 > 0」這種固定期間標籤。用 **三重障礙法**：

```text
對每個訊號時點，設定三條線：
  上障礙  +2σ × 目標倍數      → 標籤 +1
  下障礙  -1σ × 停損倍數      → 標籤 -1
  時間障礙 N 個交易日          → 標籤 0（或依當時報酬符號）
先碰到哪條，就是那個標籤
```

理由：這才符合交易員實際的出場邏輯，而且標籤自然包含了風險報酬比。
障礙寬度用**當時的波動率**縮放，否則高波動股永遠先碰到障礙。

另外必做 **sample weighting**：重疊期間的樣本不是獨立的，要用
「唯一性權重」降權，否則模型會嚴重高估自己的樣本數。

## 5. 驗證方法論（做錯這裡，前面全白做）

### 5.1 Walk-forward，不是隨機切分

```text
|--訓練 24m--||--禁區 1m--||--測試 3m--|
              |--訓練 24m--||--禁區 1m--||--測試 3m--|
                            ...往前滾
```

- **禁區（purge/embargo）不可省**：標籤有前瞻期間，訓練集末端與測試集開頭
  重疊的樣本必須刪掉，否則資訊洩漏。
- 隨機 K-fold 在時序資料上是**明確錯誤**，會給出漂亮但假的分數。

### 5.2 必須報告的指標

| 指標 | 為什麼 |
| --- | --- |
| 扣成本後 Sharpe | 未扣成本的 Sharpe 沒有意義 |
| Deflated Sharpe Ratio | 修正「試了 500 組參數挑最好那組」的多重測試偏誤 |
| 最大回撤與回撤持續期 | 交易員能不能撐過去 |
| 換手率與成本佔比 | 成本吃掉多少 alpha |
| 容量（capacity） | 多大部位會把 edge 打掉 |
| 對 benchmark 的資訊比率 | 是不是只是變相的 beta |

現有 `metrics.py` 的 `performance_summary()` 與 `drawdown()` 是起點，
需要補上 DSR、換手率、容量分析。

### 5.3 過度配適的紅旗

出現以下任一，直接退回重做：

- 參數稍微變動（±10%）績效就崩 → 曲線配適
- 只有某一年賺 → 運氣或單一 regime
- 移除任一特徵績效就崩 → 依賴單點
- 樣本外 Sharpe < 樣本內的一半 → 典型過擬合
- 交易次數 < 100 → 統計上什麼都證明不了

### 5.4 對抗自己

系統應該自動跑這些檢驗：

- **隨機化測試**：把標籤隨機打亂重跑，若績效仍好，代表流程有洩漏
- **成本壓力測試**：把交易成本乘 3 倍，還活著嗎
- **延遲壓力測試**：訊號延後 1 根 K 棒執行，衰減多少
  （衰減超過 50% 代表這個 edge 你抓不到）

## 6. 模型生命週期

```text
提案 → 回測 → walk-forward → paper 60 天 → 小額 live → 全額
                    ↑                                     │
                    └──────── 監控與再訓練 ◄──────────────┘
                                  │
                          衰減偵測 → 降權 → 退役
```

- **每個模型上線時就寫好退場條件**：例如「滾動 60 日 Sharpe < 0 連續 20 天，
  自動降權 50%；連續 40 天，自動停用」。這是自動化的，不需要人下決心。
- **再訓練頻率**要固定且事先宣告（例如每季），臨時再訓練＝人在偷偷干預。
- **模型漂移監控**：比較訓練期與當前的特徵分佈（PSI / KL divergence），
  分佈明顯偏移就告警——模型看到的世界已經不是它學過的世界了。
